## 价格规则

### 可参与正式最低价的商品

必须同时满足：

- 生效匹配状态为 `MATCH`（人工确认 MATCH 可生效）。
- `skuVerificationStatus = VERIFIED`。
- `priceVerificationStatus = VERIFIED`。
- 目标 SKU 价格大于 0。
- 币种明确。
- 能归入明确比较分组。

以下不参与正式排名：列表价、起售价、未核验的最低 SKU 价、币种未知价、1688 批发价。

### comparisonGroup

| 分组 | 判定 |
|---|---|
| `TARGET_SINGLE` | 目标单款 SKU（名称不含组合/全套标记） |
| `TARGET_BUNDLE` | 含 `+`、组合、套装、2 款等标记的 SKU |
| `TARGET_FULL_SET` | 全系列、全套、合集、all-in、6 款等标记的 SKU |
| `WHOLESALE` | 1688 批发价，独立展示，不进入零售最低价 |

真实数据验证中发现并修复了 `allin 6款` 被归入单款的问题；现在全系列最低价为 ¥75.80，不再拉高单款区间。

## 后端 API

`GET /api/searches/:id` 新增 `priceSummary`：

- `bestPrice` / `bestComparisonGroup`：默认优先单款，其次组合装、全系列；1688 不参与。
- `bestByGroup`：每个分组的最低已确认价格。
- `groups`：每个分组的 min/max/currency/verifiedCount。
- `platforms`：每个平台的零售分组汇总与 1688 批发采购条件。
- `items`：参与正式比较的 SKU 价格明细。
- `potentialCheaperCandidateIds`：同分组中可能低于已确认最低价的 UNCERTAIN 候选。
- `otherUncertainCount`：其余不合理或价格未知的待确认数量。
- `unverifiedMatchCount`：已匹配但未取得目标 SKU 价格的商品数量。
- `totalConfirmed`：有正式价格的唯一商品数。

实现：[price-summary.util.ts](../backend/src/search/price-summary.util.ts)、[price-summary.dto.ts](../backend/src/search/dto/price-summary.dto.ts)。前端只展示后端结果，不自行计算价格。

- 搜索完成后，表单下方先显示「当前最低已确认价格」卡片和平台价格概览。
- 统一商品列表按 comparisonGroup → 价格排序，不再需要逐个平台 Tab 比较。

- UNCERTAIN 只有可能刷新同组最低价时才进入「可能更便宜 · 待确认」，其余进入「其他待确认」。
- 商品卡片默认只保留图片、标题、店铺、平台、目标 SKU/组合名、价格、状态与操作；AI 描述、SKU 列表、来源对比、判断依据、原始数据全部进入「更多信息」。

## 真实数据验证（1617c7b6）

- 最优已确认价格：**¥18.80，淘宝**，目标 SKU「小镇一角【特油亮膜】」。
- 淘宝单款区间：¥18.80～¥27.30，4 个已确认。
- 组合装最低：¥29.80（区间 29.80～52.00，4 个已确认）。
- 全系列最低：¥75.80（区间 75.80～76.90，3 个已确认）。
- 抖音、小红书有匹配商品，但详情未返回目标 SKU 价格，显示「暂无已确认价格」。
- 1688 本次搜索超时，未返回候选，显示「采集失败」，未扣费。
- 41 个已匹配商品因价格未核验被折叠；11 个待确认商品中没有价格低于已确认单款最低价的候选，因此「可能更便宜」为空。
- 浏览器预览已验证：最低价卡片、平台概览、分组价格、主列表 4 个已确认价格商品、41 个价格待核实折叠项、11 个其他待确认折叠项。

## 已知限制

- 抖音/小红书详情接口通常不提供 SKU 级价格；只有匹配、没有目标 SKU 价格时不会进入正式最低价。
- 1688 本次超时；批发汇总逻辑已有单元测试，但需要在 1688 成功返回时再做一次真实展示验证。
- 多币种、价格过期、已下架状态的完整处理仍需后续数据支持；当前只对币种明确的 CNY 商品做正式排名。
- 移动端布局已做响应式处理，尚未做完整真机回归。

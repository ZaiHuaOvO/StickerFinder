## 7. 建议（按优先级）

1. **修复安全层的“有提示就降级”规则**：视觉不可用/信息缺失只应下调置信度并设置 `visualMatch=VISUAL_UNAVAILABLE`，不应单独把 MATCH 改为 UNCERTAIN。仅在置信度低于阈值、匹配类型无效、证据缺失或类别/系列/款式冲突时降级。或者在上传参考图时启用视觉比对，避免无意义的 0.1 惩罚。
2. **增加取消/停止能力**：提供 `POST /api/searches/:id/cancel` 或前端“停止搜索”按钮；编排器在每个候选、每个平台之间检查取消标志，并把 run 标记为 INTERRUPTED/CANCELLED。关闭页面时提示“后台仍在运行”。
3. **并行化平台搜索与 AI 识别**：先并行启动各平台搜索，再对识别任务使用有界并发（如 3–5）；至少不要用 20 条串行 AI 调用阻塞下一个平台的采集。
4. **改进淘宝去重**：搜索响应无店铺时，按规范化标题 + 价格 + 主图 hash 合并，或在详情补充后按真实店铺/商品 ID 再合并；重复标题至少在 UI 标记。
5. **目标输入规范化**：对系列名做异体字归一（姸→妍）、去空格、大小写/全半角归一，并允许把常见别名加入 aliases。
6. **进度可视化**：在渠道卡片显示“采集中/识别中 x/y/已完成”，避免用户误以为卡死。
